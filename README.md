# Landing Page of LMS
This is a Landing Page for LMS.


# Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/Project-LMS-by-SN/LMS-Landing-Page.git
```

---

## 2. Change your Directory

```bash
cd LMS-Landing-Page
```
---
## 3. Install Dependencies

```bash
npm install
```
---

## 4. Start the Application

```bash
npm run dev
```
